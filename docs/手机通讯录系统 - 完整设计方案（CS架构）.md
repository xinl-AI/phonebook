#### 2.2 数据表结构

**表1：user（用户表）**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | 主键，自增 | 用户ID |
| username | VARCHAR(50) | 非空，唯一 | 用户名（登录账号） |
| password | VARCHAR(255) | 非空 | 密码（BCrypt加密） |
| nickname | VARCHAR(50) | | 昵称 |
| phone | VARCHAR(20) | 唯一 | 手机号 |
| email | VARCHAR(100) | 唯一 | 邮箱 |
| avatar | VARCHAR(500) | | 头像URL |
| gender | TINYINT | 默认0 | 性别：0未知 1男 2女 |
| status | TINYINT | 默认1 | 状态：0禁用 1正常 |
| role | VARCHAR(20) | 默认'user' | 角色：user/admin |
| last_login_time | DATETIME | | 最后登录时间 |
| create_time | DATETIME | 默认当前时间 | 注册时间 |
| update_time | DATETIME | 默认当前时间 | 更新时间 |

**表2：contact（联系人表）**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | 主键，自增 | 联系人ID |
| user_id | BIGINT | 外键→user(id) | 所属用户ID |
| name | VARCHAR(50) | 非空 | 姓名 |
| phonetic_name | VARCHAR(100) | | 拼音（用于搜索排序） |
| phone | VARCHAR(20) | 非空 | 主电话号码 |
| second_phone | VARCHAR(20) | | 备用电话 |
| email | VARCHAR(100) | | 邮箱 |
| second_email | VARCHAR(100) | | 备用邮箱 |
| address | VARCHAR(200) | | 地址 |
| birthday | DATE | | 生日 |
| company | VARCHAR(100) | | 公司 |
| position | VARCHAR(50) | | 职位 |
| website | VARCHAR(200) | | 个人网站 |
| remark | VARCHAR(500) | | 备注 |
| is_favorite | TINYINT | 默认0 | 是否收藏：0否 1是 |
| avatar | VARCHAR(500) | | 头像URL |
| is_deleted | TINYINT | 默认0 | 软删除：0未删除 1已删除 |
| create_time | DATETIME | 默认当前时间 | 创建时间 |
| update_time | DATETIME | 默认当前时间 | 更新时间 |

**表3：group（分组表）**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | 主键，自增 | 分组ID |
| user_id | BIGINT | 外键→user(id) | 所属用户ID |
| name | VARCHAR(50) | 非空 | 分组名称 |
| color | VARCHAR(10) | 默认'#07C160' | 分组颜色 |
| icon | VARCHAR(50) | | 分组图标 |
| sort_order | INT | 默认0 | 排序序号 |
| contact_count | INT | 默认0 | 联系人数（冗余） |
| is_system | TINYINT | 默认0 | 是否系统分组 |
| create_time | DATETIME | 默认当前时间 | 创建时间 |
| update_time | DATETIME | 默认当前时间 | 更新时间 |

**表4：contact_group（联系人-分组关联表）**

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT | 主键，自增 | 关联ID |
| contact_id | BIGINT | 外键→contact(id) | 联系人ID |
| group_id | BIGINT | 外键→group(id) | 分组ID |
| create_time | DATETIME | 默认当前时间 | 关联时间 |


### 三、API接口设计

#### 3.1 统一响应格式

| 场景 | code | message | data |
|------|------|---------|------|
| 成功 | 200 | success | 返回数据 |
| 参数错误 | 400 | 具体错误信息 | null |
| 未授权 | 401 | 请先登录 | null |
| 无权限 | 403 | 无权限访问 | null |
| 资源不存在 | 404 | 资源不存在 | null |
| 服务器错误 | 500 | 服务器内部错误 | null |

#### 3.2 认证模块接口（/api/auth）

| 接口 | 方法 | 路径 | 请求参数 | 响应 | 说明 |
|------|------|------|----------|------|------|
| 注册 | POST | /api/auth/register | username, password, phone?, email? | userId, username | 新用户注册 |
| 登录 | POST | /api/auth/login | username, password | token, userInfo | 登录获取Token |
| 退出 | POST | /api/auth/logout | - | - | 退出登录 |
| 获取用户信息 | GET | /api/auth/me | Header: Token | userInfo | 获取当前用户 |
| 修改密码 | PUT | /api/auth/password | oldPassword, newPassword | - | 修改密码 |
| 发送验证码 | POST | /api/auth/code | phone/email, type | - | 发送验证码 |

#### 3.3 联系人模块接口（/api/contacts）

| 接口 | 方法 | 路径 | 请求参数 | 响应 | 说明 |
|------|------|------|----------|------|------|
| 获取列表 | GET | /api/contacts | page, size, groupId, keyword | list, total | 分页查询 |
| 获取收藏 | GET | /api/contacts/favorite | - | list | 收藏联系人 |
| 获取详情 | GET | /api/contacts/{id} | - | contact | 查询详情 |
| 添加 | POST | /api/contacts | name, phone, email, groupIds... | id | 新增联系人 |
| 编辑 | PUT | /api/contacts/{id} | name, phone, ... | - | 修改联系人 |
| 删除 | DELETE | /api/contacts/{id} | - | - | 软删除 |
| 批量删除 | DELETE | /api/contacts/batch | ids[] | deletedCount | 批量删除 |
| 搜索 | GET | /api/contacts/search | keyword, groupId | list | 关键词搜索 |
| 切换收藏 | PUT | /api/contacts/{id}/favorite | isFavorite | - | 收藏/取消 |
| 导出 | GET | /api/contacts/export | format=vcf | 文件流 | 导出vCard |

#### 3.4 分组模块接口（/api/groups）

| 接口 | 方法 | 路径 | 请求参数 | 响应 | 说明 |
|------|------|------|----------|------|------|
| 获取列表 | GET | /api/groups | - | list | 所有分组 |
| 创建 | POST | /api/groups | name, color? | id | 新增分组 |
| 编辑 | PUT | /api/groups/{id} | name, color? | - | 修改分组 |
| 删除 | DELETE | /api/groups/{id} | moveToId? | - | 删除分组 |
| 获取分组联系人 | GET | /api/groups/{id}/contacts | page, size | list, total | 分组内联系人 |
| 移动联系人 | POST | /api/groups/move | contactIds[], groupIds[] | - | 批量移动 |
| 调整排序 | PUT | /api/groups/sort | groupIds[] | - | 排序 |

#### 4.3 功能模块说明

**模块一：用户认证**
- 用户注册：填写用户名、密码、手机号/邮箱
- 用户登录：账号密码登录，服务端返回Token
- Token管理：客户端存储Token，每次请求携带
- 自动登录：启动时检查本地Token有效性

**模块二：联系人管理**
- 列表展示：按分组或字母索引分组展示
- 添加联系人：录入姓名、电话、邮箱、分组等
- 编辑联系人：修改已有联系人信息
- 删除联系人：支持单个删除和批量删除
- 收藏联系人：重要联系人标记收藏
- 查看详情：点击进入详情页，查看完整信息

**模块三：分组管理**
- 默认分组：系统预置"家人""朋友""同事"等
- 创建分组：用户自定义分组
- 编辑分组：修改分组名称和颜色
- 删除分组：删除后联系人移至默认分组
- 移动联系人：将联系人分配到不同分组

**模块四：搜索功能**
- 关键词搜索：按姓名、电话、邮箱搜索
- 实时搜索：输入时实时显示结果
- 分组筛选：按分组筛选联系人

**模块五：快捷操作**
- 拨打电话：调用系统拨号器
- 发送短信：调用系统短信应用
- 发送邮件：调用系统邮件应用

### 八、文档编写清单

| 序号 | 文档名称 | 核心内容 | 建议负责人 |
|------|----------|----------|------------|
| 1 | 需求规格说明书 | 数据流图（顶层/0层/1层）、数据字典、功能需求、非功能需求 | 1-2人 |
| 2 | 概要设计说明书 | 系统结构图、模块结构图、接口设计、数据库E-R图 | 1-2人 |
| 3 | 详细设计说明书 | NS图、PAD图、各模块输入输出描述、算法逻辑 | 每人负责自己模块 |
| 4 | 测试计划/报告 | 测试用例（白盒10个+黑盒5个）、测试结果、缺陷报告 | 1人 |


### 九、开发工作量预估

| 阶段 | 工作内容 | 预估天数 | 并行说明 |
|------|----------|----------|----------|
| 环境搭建 | 后端+前端开发环境配置 | 1天 | 全员并行 |
| 需求分析 | 编写需求规格说明书 | 2天 | 需求组2人 |
| 概要设计 | 编写概要设计说明书 | 2天 | 设计组2人 |
| 详细设计 | 编写详细设计说明书（各模块） | 2天 | 每人独立完成 |
| 后端开发 | 用户认证、联系人CRUD、分组管理API | 3天 | 后端1-2人 |
| 前端开发 | 登录注册、联系人列表、详情、添加编辑 | 3天 | 前端1-2人 |
| 前后端联调 | 接口对接、问题修复 | 1天 | 全员 |
| 测试 | 编写测试用例、执行测试 | 1天 | 测试1人 |
| 报告整合 | 小组报告汇总、排版 | 1天 | 组长+排版员 |

### 十、注意事项

| 序号 | 注意点 | 说明 |
|------|--------|------|
| 1 | 功能范围 | 只实现基础CRUD、分组、搜索、拨号短信即可，不做复杂功能 |
| 2 | 图表要求 | 需求阶段必须有3层数据流图，详细设计必须有NS图和PAD图 |
| 3 | 测试用例 | 必须覆盖正常值、临界值、非法错误输入，不少于15个 |
| 4 | 文档格式 | 严格按照指导书要求排版（行距固定18磅、页边距等） |
| 5 | 分工明确 | 汇总报告封面和正文需标注各模块完成人 |
| 6 | 答辩准备 | 编码人员现场演示全部功能，PPT禁止朗读文档 |
